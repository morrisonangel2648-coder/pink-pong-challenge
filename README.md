# Pink Pong Challenge 🏓

A modern, browser-based take on the classic arcade game. This project focuses on smooth physics, responsive input handling, and a polished "Neon Boutique" visual style.

### 🚀 Key Features
- **Dynamic Difficulty:** Three AI tiers (Easy, Medium, Hard) with varied reaction speeds and tracking logic.
- **Velocity Scaling:** Ball speed increases slightly with each paddle hit to create escalating tension.
- **Fluid Controls:** Optimized for desktop play using Keyboard Event Listeners (Arrow Keys).
- **Modern UI:** Built with CSS3 Gradients and a custom radial-dot pattern for a professional finish.

### 🛠️ Tech Stack
- **Language:** JavaScript (ES6+)
- **Rendering:** HTML5 Canvas API
- **Styling:** CSS3 (Flexbox, Variables, and Keyframe Animations)
